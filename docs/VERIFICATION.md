# Compatibility checks

[Deutsch](VERIFICATION-de.md)

The unpublished maintenance tree is checked on WordPress 6.7 single-site and WordPress 7.1.2 Multisite with PHP 8.4.5 and SQLite. Coverage includes toolbar positioning/depth, classic/block themes, shared-menu permissions, upload routes/nonces, individual and bulk candidate validation, single/network activation, new-site inheritance, network-specific deletion preferences and shared-host retention.

Informal and formal German host catalogs cover 408 messages, including Library and Updater messages. Local release history is escaped structured HTML; the controller retains local dialogs, link fallback and focus return. PHP syntax, metadata, documentation links and the isolated validation package are checked separately.

The declared WordPress 6.7/PHP 8.2 minimums are unchanged. This maintenance tree has not yet run on PHP 8.2 or a live production update. SQLite checks do not constitute a MySQL/MariaDB benchmark. Real third-party integration products, persistent object-cache services, FTP/SSH installation, native browser Escape/mobile behavior after these changes and a complete old/new host matrix still require separate acceptance. No new stable release or replacement release ZIP is published here.

The uploader preparation adds 24 dedicated provider/ZIP checks on each installation type, 9 checks against the canonical Leitstand 1.0.0 classes, 12 authenticated HTTP cases, and 10 headless browser cases for desktop/mobile, preview review, native installer handoff and no-JavaScript operation. Browser checks use an isolated profile and intercept the final installation handoff; no real extension is installed by that browser test. Leitstand source is referenced in place for compatibility testing and is not included in this public plugin.

Menu-preview additions: 12 single-site and 14 Multisite checks, 5 default-transition checks on each type, 8 authenticated HTTP preview cases and 10 browser cases for draft depth/grouping, escaped labels, missing anchors, unchanged saved settings, toolbar ordering, mobile layout and no-JavaScript output. The final ZIP passes 58/78 integration, 24 uploader, 12/14 preview, 5 default-transition and 1,031 compliance checks on unpacked single/network fixtures.

Save-bar UX: 16 isolated browser checks cover sticky positioning, broad/tall label field, preview-before-summary, dirty/reverted values, reload cancellation, native leave warning, native save and no-JavaScript form submission, keyboard disclosure and mobile width. Desktop/mobile preview images were visually inspected.
