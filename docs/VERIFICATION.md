# Compatibility checks

[Deutsch](VERIFICATION-de.md)

The unpublished maintenance tree is checked on WordPress 6.7 single-site and WordPress 7.1.2 Multisite with PHP 8.4.5 and SQLite. Coverage includes toolbar positioning/depth, classic/block themes, shared-menu permissions, upload routes/nonces, individual and bulk candidate validation, single/network activation, new-site inheritance, network-specific deletion preferences and shared-host retention.

Informal and formal German host catalogs cover 340 messages, including Library and Updater messages. Local release history is escaped structured HTML; the controller retains local dialogs, link fallback and focus return. PHP syntax, metadata, documentation links and the isolated validation package are checked separately.

The declared WordPress 6.7/PHP 8.2 minimums are unchanged. This maintenance tree has not yet run on PHP 8.2 or a live production update. SQLite checks do not constitute a MySQL/MariaDB benchmark. Real third-party integration products, persistent object-cache services, FTP/SSH installation, native browser Escape/mobile behavior after these changes and a complete old/new host matrix still require separate acceptance. No new stable release or replacement release ZIP is published here.
