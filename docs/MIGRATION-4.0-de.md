# Umstieg von 3.x

[English](MIGRATION-4.0.md) · [Deutsch](MIGRATION-4.0-de.md)

Für einzelne WordPress-Websites und Multisite-Netzwerke. Beide werden seit 2012 unterstützt.

Vorhandene WordPress-Menüs und die Theme-Menüposition mstba_menu bleiben verfügbar. Wähle Quellwebsite und Menü ausdrücklich, um unabhängig von Theme-Wechseln zu sein. Die automatische Gruppenbeschriftung folgt dem Menünamen. Prüfe eigene 3.x-Anpassungen; entfernte veraltete Ziele werden nicht wieder eingeführt.

Voraussetzungen sind WordPress 6.7/PHP 8.2. Gemeinsame Multisite-Menüs bleiben für Super-Administratoren geschützt. Netzwerkaktivierung wird für netzwerkweite Verfügbarkeit empfohlen; in 4.1.0 ist auch Einzelaktivierung möglich, mit netzwerkweiter Konfiguration durch einen Super-Administrator auf der aktiven Website. Sichere die Installation vor einem großen Versionswechsel. Die persönliche Frontend-Toolbar-Option im Benutzerprofil wird weiterhin berücksichtigt.
