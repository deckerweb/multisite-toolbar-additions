# Multisite Toolbar Additions 4.0.0

## English

Configurable toolbar menus, protected shared Multisite menus and independent Plugin/Theme upload shortcuts. Requires WordPress 6.7+ and PHP 8.2+. Existing WordPress menus remain; review custom 3.x snippets before upgrading.
